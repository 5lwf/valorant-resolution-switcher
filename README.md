# VALORANT Resolution Switcher

A Windows GUI utility that monitors VALORANT and changes the display resolution while the game is running.

## Run

Requires Python 3.11 or newer on Windows.

```powershell
pip install -r requirements.txt
python strech_val.py
```

Defaults to 1080 x 1080 in game and 1920 x 1080 afterward. Adjust GAME_RES and NORMAL_RES at the top of the script to match modes supported by your monitor. Start and stop monitoring using the GUI. This utility changes Windows display settings.

Independent project; not affiliated with Riot Games.
